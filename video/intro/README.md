# Intro video

The 63-second intro on [paywall.sanikant.dev](https://paywall.sanikant.dev/#watch-the-1-minute-intro),
made in code with [HyperFrames](https://hyperframes.heygen.com): HTML scenes animated with GSAP and
rendered frame by frame to MP4. The final file is [`art/intro.mp4`](../../art/intro.mp4).

- `index.html`: the root composition: nine scene slots, the voiceover and the sound effects.
- `compositions/*.html`: one file per scene, generated by `tools/build_scenes.py` (edit the script).
- `SPEC.md` / `STORYLINES.md`: the brief: look, timing per scene, what's banned.
- `SCRIPT.md`: the narration. Voice: ElevenLabs "Liam", model `eleven_multilingual_v2`.
  `assets/audio/voiceover.words.json` holds its word timings, which drive every scene.
- `tools/make_vtt.py`: builds the captions (`intro.en.vtt`) from those timings.
- Fonts: Google Sans Flex and Google Sans Code (SIL OFL 1.1, licences in `assets/fonts/`).
- Screens are real screenshots and a real recording of the demo app on an emulator.
- Sound effects: the HyperFrames bundled library.

## Rebuild

```bash
python3 tools/build_scenes.py
npx hyperframes check
npx hyperframes render -o renders/intro.mp4 --quality high
# loudness to about -15 LUFS for the web
ffmpeg -i renders/intro.mp4 -c:v copy -af "loudnorm=I=-15:TP=-1.5:LRA=11" -c:a aac -b:a 192k -movflags +faststart ../../art/intro.mp4
```

Regenerating the voiceover needs your own ElevenLabs API key in the `ELEVENLABS_API_KEY`
environment variable. Never commit a key.
