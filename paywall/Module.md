# Module m3-expressive-paywall

Six Material 3 Expressive paywall screens for Jetpack Compose. Billing-agnostic: every paywall takes
`PaywallPlan`s plus `onPurchase`, `onRestore` and `onClose` callbacks.

Guides and live examples: [paywall.sanikant.dev](https://paywall.sanikant.dev)

# Package dev.sanikant.m3.paywall

The public paywall composables and their data classes.
