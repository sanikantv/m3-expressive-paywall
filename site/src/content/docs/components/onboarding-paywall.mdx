`OnboardingPaywall` is design 6 of [M3 Expressive Paywall](/). A short `HorizontalPager` of benefit pages that ends in the plan selection. A Skip button jumps to the plans, and the legal footer appears on the plan page, where buying becomes possible.

## When to use it

- The paywall is the last step of your onboarding.
- You want to explain value before you ask for money.

## Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `pages` | `List<BenefitPage>` | required | Benefit pages shown before the plans. Three or four work best. |
| `plans` | `List<PaywallPlan>` | required | Plans on the last page. |
| `legal` | `PaywallLegal` | required | Terms and Privacy URLs for the footer links. |
| `onPurchase` | `(PaywallPlan) -> Unit` | required | Called with the selected plan when the button is tapped. Start your billing flow here. |
| `onRestore` | `() -> Unit` | required | Called from the Restore link. |
| `onClose` | `() -> Unit` | required | Called from the close button. |
| `modifier` | `Modifier` | `Modifier` | Applied to the paywall's root. |
| `plansTitle` | `String` | "Ready to go Pro?" | Headline of the plan page. |
| `plansSubtitle` | `String?` | "Pick a plan to keep everything you just saw." | Line under it. |
| `initialPlanId` | `String?` | `null` | Plan to preselect. |
| `pagerState` | `PagerState` | `rememberPagerState { pages.size + 1 }` | Pager state, for example to start on the plan page. |


Full signature: [OnboardingPaywall in the API reference](/api/m3-expressive-paywall/dev.sanikant.m3.paywall/-onboarding-paywall.html).

## Customization

The page count is `pages.size + 1`; the extra page is the plan selection. Pass your own `pagerState` to control it.

## Accessibility

- The page indicator announces "Page 2 of 4".
- Skip and Next are real buttons, so the carousel works without swiping.

## Common mistakes

- Treating `onClose` as "cancel onboarding". Usually it should finish onboarding and continue to the free experience.
- Long benefit copy. One line of title and one or two lines of description per page.
