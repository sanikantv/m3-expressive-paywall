**Short answer:** load your subscription with `queryProductDetails`, turn each
`SubscriptionOfferDetails` into a plan (price from the last pricing phase, trial from a free
phase, offer token as the id), and call `launchBillingFlow` with that offer token when the user
taps the paywall's button.

<Aside>
  Setting up the `BillingClient` connection and handling `PurchasesUpdatedListener` are covered in
  Google's [Integrate the Google Play Billing Library](https://developer.android.com/google/play/billing/integrate)
  guide. This page covers the part between the billing data and your Compose UI.
</Aside>

## Add the dependency

```kotlin
implementation("com.android.billingclient:billing-ktx:9.1.0")
```

## Tips and common mistakes

- **Multiple base plans.** If monthly and yearly are separate base plans of one product,
  `subscriptionOfferDetails` lists both; the mapper above handles that. If they are separate
  products, query both and concatenate the plans.
- **Don't show offers the user isn't eligible for.** Play returns only the offers this user can
  buy, so a free trial disappears for users who already used it. Don't cache old plans.
- **Wait for products before showing the paywall.** Show a loading state instead of an empty
  plan list. The paywall needs at least one plan.
