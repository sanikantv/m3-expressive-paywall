## Why this library

<CardGrid>
  <Card title="material3 gives you parts, not a paywall" icon="puzzle">
    Compose has buttons, cards and sheets. A paywall also needs plan selection, a trial
    explanation, the auto-renew text and a restore path. These templates put all of that on
    one screen, already wired together.
  </Card>
  <Card title="Expressive, without the research" icon="rocket">
    `ButtonGroup`, `MaterialShapes` morphing, `LinearWavyProgressIndicator` and spring motion
    are new in material3 1.5. The paywalls use them, so you see working examples instead of
    API reference pages.
  </Card>
  <Card title="Disclosures come with every screen" icon="approve-check">
    The price, billing period, trial terms and auto-renew line sit next to the button, which
    is what [Google Play's subscription policy](/guides/google-play-subscription-paywall-requirements/)
    asks for. Restore, Terms and Privacy links are in the same footer.
  </Card>
  <Card title="No billing lock-in" icon="setting">
    Each paywall takes a list of `PaywallPlan`s and three callbacks. Connect it to
    [Google Play Billing](/guides/connect-paywall-google-play-billing/),
    [RevenueCat](/guides/connect-paywall-revenuecat/) or your own backend. No API keys, no dashboard.
  </Card>
</CardGrid>

## Common questions

- **Does it work with stable material3?** It needs `1.5.0-beta02` or newer, because the Expressive APIs it uses are not in 1.4. [Read the FAQ](/faq/#does-it-work-with-stable-material3)
- **Do I need RevenueCat or another SDK?** No. Any billing source works, as long as you can turn its products into `PaywallPlan`s. [Read the FAQ](/faq/#do-i-need-revenuecat-or-another-billing-sdk)
- **Does it support dark mode and dynamic color?** Yes. Every color comes from your `MaterialTheme`. [Read the FAQ](/faq/#does-it-support-dark-mode-and-dynamic-color)
- **Is it free for commercial apps?** Yes, it is MIT licensed. [Read the FAQ](/faq/#is-it-free-for-commercial-apps)
